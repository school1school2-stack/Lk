# 📅 Age Analytics & Hijri Converter

تطبيق ويب متطور لحساب العمر بدقة متناهية، التحويل بين التقويم الميلادي والهجري (أم القرى)، وحساب الأيام المتبقية ليوم الميلاد.

## ✨ المميزات
- **واجهة Glassmorphism:** تصميم عصري يعتمد على الشفافية وتأثيرات النيون.
- **دقة عالية:** الاعتماد على مكتبة `moment-hijri` للتقويم الهجري.
- **تجاوب كامل:** يعمل بسلاسة على كافة الشاشات (Mobile/Desktop).
- **تجربة مستخدم (UX):** توزيع منطقي للبيانات مع أيقونات توضيحية.

## 🚀 التقنيات المستخدمة
- HTML5 / CSS3 (Custom Gradients & Animations)
- JavaScript (Vanilla)
- Moment.js & Moment-Hijri
- FontAwesome Icons

## 🛠️ كيفية التشغيل
فقط قم بفتح ملف `index.html` في أي متصفح، أو ارفعه على **GitHub Pages** ليصبح رابطاً مباشراً.
